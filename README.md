# TripTracker

TripTracker is a comprehensive **travel expense management application** designed to simplify tracking and managing your travel expenses across trips.

## ✨ Features

- **User Authentication** – Secure sign-in/sign-up using Firebase Authentication.
- **Trip Management** – Create and manage trips with name, location, dates, and status.
- **Expense Tracking** – Add, edit, and remove expenses with purpose, amount, category, and date.
- **Expense Categorization** – Organize spending into categories for better insights.
- **Dashboard Overview** – See summaries of travel costs, recent expenses, and active trips.
- **Profile Settings** – Manage your profile and preferences.
- **Cross-Platform** – Built with .NET MAUI for deployment on desktop and mobile platforms.

## 🎯 Target Users

- **Business Travelers** – Manage expenses for reimbursements.
- **Leisure Travelers** – Monitor spending while on vacation.
- **Budget-Conscious Travelers** – Keep track of budgets for trips.

## 💡 Benefits

- Real-time expense tracking and categorization.
- Easy budgeting with summaries and analytics.
- Organized trip management for multiple journeys.
- Secure authentication and data handling.

## 🛠️ Tech Stack

- **.NET MAUI / Blazor Hybrid**
- **Firebase Authentication**
- C#, XAML, and Razor components

## 📂 Project Structure

- **Data** – Models and data handling
- **Pages** – UI pages for trips, expenses, and settings
- **Services** – Business logic and Firebase integration
- **ViewModels** – MVVM pattern implementation
- **wwwroot** – Static assets
